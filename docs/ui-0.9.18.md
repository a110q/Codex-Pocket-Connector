# 0.9.18 / build 62 界面优化

工作空间减少重复标题、卡片与整行状态铺色，保留真实运行、审批与未读状态。项目新建入口在项目菜单，全局新建仍在工具栏。长对话标题允许两行。

聊天文件区减少边框和嵌套；窄屏或大字号时，电脑切换放到标题下方，返回、标题、菜单与连接状态仍可操作。桌面连接页统一浅灰与靛蓝配色，整理间距、焦点和窄屏布局。

验证：252 项 Node 行为测试、33 项 Android 单测、27 项完整 UI 回归通过。另在 320dp 窄屏补测 3 项，最终聊天头部修改后在 320dp 补测 2 项、约 411dp 补测 3 项。覆盖深色、长标题、大字号、空状态、错误输入、真实文件预览、发送、停止、审批和电脑选择。Android 行为测试使用 debug 包；正式 release 包另做签名、配置和启动检查。

macOS 本地应用已启动并操作验证，签名为 ad-hoc；Windows 交叉编译和静态校验不等于 Windows 实机连接验收。Android 用户真机尚未验收。
