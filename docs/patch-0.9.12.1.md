# 0.9.12.1 申请提示与联系方式

已于 2026-10-30 22:41:42（北京时间）发布到自建更新服务，构建号 39。生产中继同步升级至 0.9.12.1，仍通过 1Panel 编排管理。GitHub 对应版本为 `v0.9.12.1`，发布附件含三端安装包与 `SHA256SUMS.txt`。

- 申请账号时，密码需要 10–128 个字符。输入不合规会显示红色提示及当前字符数；点击提交会说明原因。超长密码不会静默截断。
- 密码不强制组合大小写、数字或符号，与服务端既有规则一致。无效申请不会发送到服务器；账号、称呼和申请说明缺失时也会明确提示。
- 包含此前 0.9.11 联系方式功能：个人微信、微信群二维码可查看、放大、保存；管理员可维护说明、微信号、二维码和有效期。默认群码在 2026-11-06 前有效。
- 包含此前 0.9.12 电脑在线绿点：在线绿色、离线灰色、未知空心灰色，前台约 15 秒自动刷新。

0.9.10 及之后版本可从“检测更新”下载安装。更早版本需要先手动安装。Windows 已打包并验证公网下载，尚未进行实机连接验收。

验证与回退见 [验证记录](verification-0.9.12.1.md)。
