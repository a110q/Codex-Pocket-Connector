# 0.9.15.1 修复说明

修复电脑移除项目后，手机仍显示该项目的问题。

连接器优先使用电脑当前可见的项目清单，底层数据库仅补充仍可见项目的信息。桌面仍在迁移对话归属时，项目已复制到数据库不代表侧边栏已改用数据库；此时桌面连接暂不可用，使用当前侧边栏状态作为后备清单，避免把底层残留记录重新加回手机。成功返回空清单时清空项目，请求失败继续保留缓存。

本次仅修改连接器项目读取规则，手机沿用 0.9.15 的前台自动刷新。配对身份和对话记录保留。公开版本 0.9.15.1，构建号 44；本版同时发布三端安装包与应用内签名更新清单，沿用现有服务编排和信任配置。

验证见 [验证记录](verification-0.9.15.1.md)。
