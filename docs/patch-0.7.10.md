# 0.7.10 更新说明

- 手机首次使用展示「公网使用」「局域网使用」「自建中继」三个独立卡片，与电脑连接器保持相同分类。
- 公网进入独立登录、申请和审批状态页；局域网进入同 Wi-Fi 连接指引，直接扫码，无需账号审批；自建中继进入电脑配置指引，通过扫码获取地址与证书。
- 每个页面均可返回重选。扫码取消后留在当前指引，界面重建后仍保留所在步骤。
- 已配对电脑继续自动进入工作空间；设置顶部「选择连接方式」可回到三个卡片，也可返回当前工作空间。
- 选择公网时恢复默认服务，选择自建服务后仍需确认地址与指纹；不同服务继续隔离账号及配对信息。

电脑连接与桌面同步协议未改变。三端版本统一为 0.7.10，手机请覆盖更新 APK。详情见 [验收记录](verification-0.7.10.md)。Windows 11 仍待实机连接验收。
