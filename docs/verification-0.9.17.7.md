# 0.9.17.7｜手机删除同步到电脑

- 手机确认后，由配对的电脑连接器执行 Codex 的删除操作，不是只在手机列表里隐藏。去掉根据运行状态、加载状态或待确认请求禁用删除的判断。归档和恢复同样交给连接器执行。
- 目标对话由连接器自己的工作进程持有时，直接使用该进程提交操作；如果是另一个 Codex 进程拒绝，连接器保留请求并自动重试，重启后继续。手机显示「等待删除」，不会把排队显示成已删除。
- 只有读回确认电脑已删除，才刷新电脑侧栏并从手机列表移除；手机重连后也能同步结果。如果其他进程一直持有对话，不能保证立即删掉。不会退出其他客户端、改写 Codex 数据库或影响其他无关对话和项目文件。

## 验证范围

使用临时 `CODEX_HOME` 和两个独立的官方 Codex App Server 验证：电脑持有时收到待处理回执，连接器重启后保留请求，持有进程释放后自动删除；第二个 App Server 回读确认对话不可读且不在普通和归档列表，另一条对话未受影响。Windows 安装包可构建，尚未做 Windows 实机连接和原生桌面侧栏验收。
