# 0.7.9 更新说明

- 电脑首页将「自建中继」作为独立连接卡片，提供蓝色「配置服务」入口；小窗口自动改为整行卡片，保持入口完整可见。
- 中继设置使用独立面板，放大标题、表单和操作按钮，可收起并保留未提交内容；地址校验失败时保留输入。
- 手机登录页和设置页顶部新增蓝色「自建中继 / 切换服务」卡片，16sp 标题，整块可点击，直接扫描电脑配对码。
- 手机从局域网扫描当前公网服务配对码时，自动转入公网模式。切换到其他服务仍需确认地址与证书指纹，再登录该服务账号。

手机和电脑均更新至 0.7.9。局域网仍无需账号审批；公网审批规则与账号隔离保持原有行为。

验证范围见 [验收记录](verification-0.7.9.md)。Windows 11 仍待实机连接验收。
