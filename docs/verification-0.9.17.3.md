# 0.9.17.3 验证记录

对外版本 `0.9.17.3`，构建号 `53`。

- 旧版在 Windows 上用不同路径拼写或目录联接启动时，Node 解析后的入口路径可能不同于命令行路径，导致进程退出 0 却未启动后台。新版使用独立入口，不以路径字符串相等作为启动条件；模块加载失败时保留明确诊断。
- 在中文 Windows 11 ARM64 虚拟机上，从 Parallels 共享目录的两层 ZIP 解压路径实际启动新版，加载 WebView2 中文界面，连接正式 Codex App Server，并生成局域网配对二维码；关闭窗口后后台进程退出，原有测试配置保留。目录联接启动也通过。此次不包含手机真机配对和 Windows x64 实机验收；单文件 EXE 完整性已检查，独立启动验收未完成。
- 对话交接、电脑归档和手机端删除接口，已用隔离对话和真实 Codex App Server 回归。未修改用户对话，也未将接口测试当作手机实机测试。
- 232 项 Node 测试通过。Windows 两种包内容一致，ZIP 清单的 935 个文件已校验。macOS App 严格临时验签及本机启动通过，未经 Apple 公证。Android APK 签名已验证，版本为 `0.9.17.3`、versionCode `53`。Windows EXE 未做 Authenticode 代码签名。
