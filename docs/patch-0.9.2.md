# 0.9.2：多电脑切换与发送恢复

Android、Windows、macOS 统一使用 **0.9.2**，中继无需升级。建议同时更新手机和电脑连接器。

## 手机快速切换与重命名

- 点击顶部电脑名称的下拉箭头，直接选择已配对电脑；当前电脑有明确标记。
- 「管理电脑与名称」可添加、移除或重命名电脑。别名保存在本手机，通知也使用该名称；不修改电脑系统名。
- 每台电脑分别保留草稿、附件、缓存与待确认操作。发送结果待确认时可以切到另一台，回到原电脑后继续核对，避免重复发消息。

## 修复发送一直等待确认

此前发送后把手机 App 切到后台，旧连接的完成回调可能被丢弃，导致界面一直显示等待电脑确认，即使电脑已处理消息。

现在切后台和重连会正确结束旧连接的等待状态，并向电脑只读查询同一操作的确认记录。收到已完成记录后恢复界面；记录未找到或结果不明时保留提示，不自动重发。电脑侧按操作 ID、动作及参数核对，确认查询本身不会启动任务。

## 修复电脑移除后无法改绑

管理员从旧账号移除电脑后，服务器会撤销旧凭据。现在点击「公网使用」或「连接 Codex」，连接器先验证身份；仅在明确 HTTP 401 时准备新的未绑定身份，生成新二维码。手机登录目标账号扫码，仍需电脑点击「允许连接」。

- 原账号的旧配对凭据继续失效；账号审批和电脑数量限制继续生效。
- HTTP 403、断网、证书和服务器错误不会重置身份。
- 响应丢失或软件重启后复用待确认身份，避免重复创建设备。
- 新身份验证通过后才替换配置，Codex 项目、对话、登录及安装位置保持不变。

## 更新

1. 退出旧电脑连接器，打开同平台 0.9.2。
2. Android 用 0.9.2 APK 覆盖安装，保留原配对和草稿。
3. 普通升级沿用现有配对。只有管理员移除电脑后需要重新生成二维码并扫码改绑。

测试范围与平台限制见 [验收记录](verification-0.9.2.md)。Windows 11 仍待实机连接验收。
