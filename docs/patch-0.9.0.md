# 0.9.0 更新说明

手机和电脑连接器均需更新到 0.9.0，中继协议不变，无需升级服务器。

- 对话支持重命名：在聊天「更多」或列表长按菜单操作，名称写回 Codex 并刷新桌面列表。
- 新增「工作空间工具」入口，集中管理项目文件、Git、技能、插件、定时任务、用量和 MCP 授权。
- 项目文件：目录浏览、分页、名称搜索、图片/PDF/代码等文件预览与保存；聊天输入 `@关键词` 可搜索文件，也可从文件树选择「@引用」。引用随文字一起发送，文件内容仍保留在电脑项目中。
- Git：真实分支、上游与工作区状态；逐文件查看已暂存/未暂存红绿差异及文件行号；选择文件、检查说明后提交；确认后推送；使用已登录的 GitHub CLI 创建草稿 PR。审查可针对未提交修改或基础分支，结果进入当前聊天。
- 技能：查看真实列表与内容、启停、在对话使用；创建本地技能，编辑/删除可编辑的用户技能。删除移到电脑备份目录；内置及插件技能保留受保护状态。
- 插件：查看已安装插件和市场、搜索、启停、安装与卸载。组织策略、账号资格和需官方安装告知的插件仍遵循 Codex 限制。
- Pocket 定时任务：按每日/工作日或每隔若干小时运行，支持编辑、暂停、恢复、立即执行、删除及最近 30 次启动记录。任务由电脑连接器执行，与官方桌面定时任务独立；电脑需保持开机，Codex 和连接器需运行。离线错过的任务不补发；重启不自动重放结果未知的操作。
- 用量：显示接口实际返回的账号额度、恢复时间和统计，显示当前会话累计 Token、最近上下文占用与模型窗口。实时数据不可用时可读取本地已保存的 Token 统计；缺失和认证失败明确标明，不按文本长度推算。
- 扩展审批：补齐标准 MCP 带标题单选、多选、默认值，扩展 JSON 表单完整规则校验；支持请求提供的命令前缀/网络规则审批，以及逐项目录/网络授权和后续命令自动审查选项。MCP 登录根据电脑返回的完成通知确认。

## 使用条件与边界

项目文件访问限定在明确的本机项目/会话目录，隐藏 `.private`、`.git`、依赖和构建目录，拒绝越界与符号链接。文件树单页 100 项，搜索最多 200 项；结果达到限制会提示缩小范围。单个文件预览最大 50 MB。

Git 提交会校验确认时的工作区状态，拒绝夹带未选择的已暂存文件。推送只使用已配置的上游，不自动强推；PR 需要电脑安装 GitHub CLI 并完成登录，创建前需要先推送当前分支。Git 按完整仓库根目录操作，子目录项目会提示选择仓库根目录。

账号额度取决于安装 Codex 的账号和认证方式。目前这台电脑的独立 App Server 返回需要账号认证，手机会显示具体原因；这不代表额度为零。会话 Token 是最近一次已有统计，并非实时计费结果。

官方原生定时任务没有向独立连接器开放管理接口，Pocket 不会修改其任务配置。OpenAI 专用身份验证、专用 MCP 输入控件及必须查看官方安装告知的流程仍需在电脑完成，手机可查看/拒绝/取消相关请求；不会用普通确认绕过验证。第三方 OAuth 的完整成功仍取决于服务商和电脑回调，不能将打开网页视为成功。

Windows 11 包已构建与校验，但仍需实机连接验收。详见 [使用手册](USER_GUIDE.md) 和 [验证记录](verification-0.9.0.md)。
