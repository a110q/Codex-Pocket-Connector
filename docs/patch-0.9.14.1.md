# 0.9.14.1 更新说明

公开版本 0.9.14.1，构建号 42。

- 修复安卓首次更新需要允许安装来源时，返回应用后丢失已下载状态、要求重复下载的问题。安装包保存到应用持久目录，原始签名清单同步保存；页面或应用重建后可离线恢复，继续点击“安装更新”。
- 手动更新页面在系统重建后恢复打开状态；重新检测相同更新会复用已验证的安装包，检测网络失败仍可继续安装已有包。
- 恢复与安装前保留清单验签、大小、SHA-256、应用包名、版本及签名校验。缺失或损坏的包需要重新下载；成功升级后清理待安装记录及对应安装包。

安装仍由用户在系统安装器确认。本修复从本版生效；旧版安装本版时仍使用旧版更新流程，遇到旧问题可重新下载一次，或直接安装本版 APK。

沿用现有更新分发编排、证书与签名密钥；中继 0.9.12.1 兼容，无需重启账号服务。Windows 实机连接验收仍待完成。
