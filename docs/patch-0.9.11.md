# 0.9.11 联系方式

后续状态：联系方式功能已合并到 [0.9.12.1](patch-0.9.12.1.md) 上线；以下保留候选阶段记录。

状态：本地候选版本，尚未发布到更新服务或 GitHub。对外版本 0.9.11，构建号 37。

- 登录与审批页面、设置页面新增“联系我们”。个人微信和微信群二维码使用用户提供的两张原图，支持查看大图、保存到相册；填写微信号后可复制。
- 管理员设置页新增“联系方式管理”，支持更换、移除两张二维码，修改页面标题、联系说明、微信号和群码有效期。保存后其他用户重新打开页面即可读取。
- 群码提示在 2026-11-06 前使用，实际有效期以微信为准；到期后提示通过个人微信获取新群码。
- 配置保存在当前中继服务的数据库，重启后保留；普通用户及未审批用户可以查看，只有正常使用的管理员可以修改，修改会记录管理事件。
- 所有新增页面、按钮和提示使用中文。系统安装器语言跟随设备系统；测试模拟器已设置为简体中文。

发布时需要同步升级中继服务。旧版中继暂未提供配置接口时，官方服务的客户端仍可展示内置二维码；后台保存按钮会禁用并提示先升级服务端。自建服务不使用官方联系方式作为兜底。

本次没有调整线上稳定版清单；线上仍为 0.9.10。待确定发布时间后再发布 0.9.11。
