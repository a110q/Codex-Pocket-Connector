# 0.9.4：网页链接与指定电脑移除

三端统一版本 0.9.4。Android 更新后可使用新的网页打开方式；管理员移除自己的电脑需要中继同步更新。

## App 内直接打开网页

点击聊天中的 Markdown 链接或 HTTP / HTTPS 地址，会在 App 内展开网页。电脑上的 `localhost`、`127.0.0.1` 服务通过已有加密连接访问，手机无需和电脑处在同一局域网。电脑、项目服务和连接器仍需保持运行。

网页展开时隐藏聊天输入区，保留网页工具栏；点退出展开按钮或系统返回键可缩回小窗，点关闭返回聊天。文件预览仍保留原有操作。

网页加载超时会给出提示，可点「重新打开网页」重新建立预览连接。网站响应速度、项目配置和 WebView 兼容性仍会影响加载；不会关闭 HTTPS 证书校验。

## 选择要移除的电脑

用户中心按账号列出每台已绑定电脑，各自有「移除」按钮。确认窗口显示电脑名称及所属账号，取消不会改变绑定。

管理员可以移除普通用户的指定电脑，也可以移除自己绑定的指定电脑。移除后该电脑凭据失效，可重新扫码绑定；同一账号的其他电脑保持连接，管理员手机登录保持有效。电脑上的任务不会停止。

服务端继续校验管理员权限、电脑所属账号和具体电脑 ID；管理员手机及其他管理员的设备仍受保护。操作记录包含移除的电脑 ID，便于排查。

使用自建中继的用户需更新中继源码并重新构建部署。`/healthz` 返回 `deviceRemoval: selected-v1` 表示已支持本次变更。
