# 0.9.18.2 本地项目漏显示修复

本次修复一个已在 Android 上复现的缺陷：电脑明确标记为本地的项目，如果主机标识为 JSON 空值、空字符串或空白字符串，手机会将其过滤掉，造成四个项目只显示三个。

- 电脑连接器和 Android 统一这些本地项目的主机标识，空项目也正常显示。
- 会话列表、实时状态、项目归属及打开会话使用一致的本地主机标识，保留已有项目新旧 ID 映射。
- 在项目内新建会话时，继续使用当前桌面接受的项目 ID。
- 实时项目读取失败后重新读取本地元数据，避免返回请求开始前的旧清单；期间完成迁移时，按迁移后的项目来源读取。
- 回退清单标明实时读取不可用和完整性未确认。仍不把数据库残留项目直接补回桌面清单。
- 旧缓存加载、切换电脑、保存后重新读取均做相同处理。有效远程主机标识保持原值。

外显版本为 `0.9.18.2`，构建号为 `64`。修改涉及电脑连接器和 Android，正式升级需要两端同步更新。

客户现场尚未提供 YunqiPay 的实际主机标识和项目清单来源。如果桌面实时接口不可用，磁盘旧清单本身长期缺项目，现有数据不能区分“桌面新增”与“已删除残留”，此路径尚未解决，不能声称客户现场已全面修复。发布状态与验证记录见 `verification-0.9.18.2.md`。
