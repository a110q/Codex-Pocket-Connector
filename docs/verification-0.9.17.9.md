# 0.9.17.9｜macOS 跨端删除与归档

在配对电脑的连接器第二步点击「打开 Codex（跨端同步）」。若 Codex 已打开但没有使用共享服务，请先保存工作并正常退出 Codex，再点击此按钮。保持现有手机配对，无需重新扫码。

## 验证结果

- Node 回归 248 项通过，安卓对话状态回归 15 项通过。
- 隔离的真实 macOS 桌面通过连接器入口连上官方本机共享服务。安卓模拟器先取消一次删除，目标仍在；再确认删除时，连接器从共享服务执行原生删除。单次确认用时 79 毫秒，不是常态耗时承诺。
- 原生读取找不到删除目标，普通与归档列表均无目标，桌面保持在线。电脑端归档另一条对话后，安卓列表同步移除，原生归档列表保留该对话；第三条对话保持原样。
- Windows 包通过构建和归档完整性检查，未在 Windows 实机验收。本次未修复 Windows 或 macOS 私有连接模式下桌面占用导致的等待。
