# 使用手册

## 安装与首次连接

从 GitHub Releases 下载相应平台的最新版本（电脑与安卓均为 0.7.7）。电脑先安装并登录官方 Codex。Windows 直接运行 EXE，或完整解压 ZIP 后运行 `Codex-Pocket.exe`；Mac 解压得到 `.app` 并移入「应用程序」。安卓安装 APK，更新时用同签名新版覆盖安装，不必先卸载。

![首次连接](images/quick-start.png)

电脑选择连接方式，点击「连接 Codex」。识别失败时手动选择程序或安装目录。第二步成功后进入第三步显示二维码，手机扫码后在电脑确认允许。

**局域网：** 手机和电脑接入同一网络，电脑选局域网，手机点「局域网直连 · 无需账号审批」。无需登录，但仍需电脑确认。只接受私有 IPv4 地址；若连接失败，检查防火墙和 Wi-Fi 客户端隔离。公网与局域网分别保存配对。

**公网：** 电脑选公网。手机注册并申请，管理员批准后登录，再扫码并由电脑确认。电脑不需要登录 Pocket 账号或输入 SSH 信息。两端均需能访问同一中继，电脑不能休眠。

## 自建中继

电脑第一步展开「使用自建中继 / 切换服务」，填写服务的 HTTPS 地址，选择或粘贴公开 TLS 证书，再点击「验证并使用自建中继」。这里不需要服务器 root 密码、SSH 信息或中继管理令牌。

手机从登录页点击「扫描电脑配对码 / 连接自建中继」。确认服务地址与指纹后，登录或申请该服务的账号。审批由这台自建中继的管理员负责，与默认公网服务的审批相互独立。登录通过后沿用扫码结果开始配对；电脑允许后自动进入工作空间。二维码过期时在电脑更新后重扫。

手机可点击「返回默认公网服务」，电脑可点击「恢复默认公网服务」。不同服务各自保留账号和配对；不会把原服务 Token 发给其他服务器。详细部署见 [自建说明](SELF_HOSTING.md)。

## 项目和对话

首页按项目展示对话，可搜索、展开、收起。点击对话可继续聊天，查看工具调用及状态；更早历史可继续加载，长工具结果可展开详情分段读取。底部「新建对话」创建独立聊天，项目内新建入口可沿用项目。

手机新建的对话会刷新进入电脑侧栏。手机发起的一轮回复完成后会自动释放会话，电脑可继续输入；电脑继续后手机优先跟随同一条对话。运行中保留一个写入者。

长按对话可以归档、恢复或删除；删除需再次确认，运行中的任务需先停止。已归档对话可从「已归档」入口查看和恢复。停止按钮用于中断当前轮次。

若提示上一条操作结果待确认，请先核对电脑上的实际结果，避免重复执行。

## 模型、推理和权限

聊天输入区下方可以选择电脑提供的模型、推理强度和权限模式。设置写入后会重读确认，应用到后续消息；可选项取决于电脑上的 Codex 和账号权限。

遇到受支持的命令执行、文件修改审批或问题回答时，按手机提示处理。手机授予的权限和发出的指令会在电脑上生效。

## 图片、文件和网页

输入框左边的附件按钮用于添加图片，最多 4 张，可点击缩略图上的 × 移除。输入文字后点击发送，文字与所有图片进入同一条消息；也可只发图片。新建对话也有「添加图片」入口。原图最多 50 MB，手机会按最长边 2048 像素处理并移除元数据，单张处理后最多 10 MB。

发送失败会保留草稿或待确认记录。上传未完成不会发出文字。上传到电脑的图片保存在该电脑的连接器私有数据目录，用于后续聊天和图片回显。

「交付与修改」仍在对话右上角「更多 → 查看交付文件」中。

点击图片可以缩放预览。当前对话可访问的文件支持文本、代码、图片和 PDF 预览，部分文件可下载。

网页入口可访问电脑上的开发服务器。它通过电脑侧代理通道打开网页，不是远程桌面，也不复制电脑浏览器登录状态；需要登录的网站可能要在预览内重新登录。小窗支持收起、展开和关闭。

## 添加和切换电脑

点击顶部电脑名称，或进入「设置 → 我的电脑」。扫描另一台电脑的配对码并确认后，即可切换或移除。缓存和草稿按电脑隔离；未确认操作需先核对，才能切换。

公网账号默认五台电脑、一部手机；管理员可把电脑额度调整为 1–50 台。更换手机遇到设备限制时，请联系管理员移除旧设备。

## 管理员

同一个 APK 根据账号展示菜单。管理员登录后可从设置进入管理中心和用户中心，批准或拒绝申请、创建账号、停用或恢复、续期、管理设备、调整电脑额度并处理安全提醒。

没有默认管理员密码。自建服务的首个管理员通过服务端管理令牌初始化，随机密码只写入指定私密文件，见 [自建说明](SELF_HOSTING.md)。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 登录后仍需批准 | 注册只表示创建账号，需管理员批准且未到期、未停用 |
| 第三步不能点击 | 先完成第二步，确认 Codex 已登录、路径正确且连接成功 |
| 断网或睡眠后掉线 | 恢复电脑网络并唤醒，保持连接器运行，回到手机等候重连或点重连 |
| Windows 端口占用 | 新版回收自己启动的进程；首次升级前退出旧版，必要时重启电脑 |
| `was cancelled` 或重复气泡 | 更新 0.7.7；自动重读旧快照，保留配对、草稿和待确认操作 |
| 已在另一个应用中打开 | 电脑连接器更新至 0.7.7，等待本轮回复结束后点击一次「重试」；无需创建聊天分叉 |
| 手机提示 active writer | 更新电脑连接器至 0.7.7；会自动恢复桌面连接并跟随当前会话。旧黄色提示点一次「重新确认」，未发送消息回填到草稿后再发送 |
| 删除后电脑仍有入口 | 更新电脑连接器至 0.7.7；新删除会同时刷新桌面侧栏，电脑正在持有该会话时需先关闭其页面 |
| 扫码后等待电脑确认 | 在电脑连接器点击「允许连接」；临时断网会自动继续等待，可点「取消配对」返回 |
| 发送超时但电脑已有消息 | 点「重新确认」，新版按请求标识核对，不会重发。旧版模糊超时请先人工核对 |
| 想退出扫码 | 点击 X 或系统返回键 |
| 与电脑全部功能一致吗 | 目前支持常用项目、聊天、工具记录、设置和预览，完整终端等尚未覆盖 |

反馈时不要附上完整二维码、密码、Token 或真实个人对话。
