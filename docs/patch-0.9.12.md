# 0.9.12 电脑在线状态

后续状态：此候选由 0.9.12.1 替代，功能已随 [0.9.12.1](patch-0.9.12.1.md) 上线；以下保留候选阶段记录。

状态：本地候选版本，尚未发布。对外版本 0.9.12，构建号 38，包含 0.9.11 的联系方式功能。

- 用户中心和管理中心的电脑名称旁增加小圆点：绿色实心表示在线，灰色实心表示离线，灰色空心表示状态未知；读屏提供对应中文说明。
- 在线状态以中继当前的电脑 WebSocket 连接为准，单独保持手机连接、已绑定电脑或已登录账号均不会亮绿点。服务重启后不沿用之前的在线状态。
- 前台沿用约 15 秒的账号列表轮询，无需进出页面。断网后的异常连接由原有心跳机制清理，再在下次刷新时反映。
- 未成功刷新、退出前台或更换登录时，不使用旧数据点亮绿点；旧服务端未提供在线字段时显示未知状态。

需要同步部署新版中继，客户端才能读取在线字段。此次仅生成候选安装包，没有修改线上更新清单或发布到 GitHub；发布时间仍由用户决定。
