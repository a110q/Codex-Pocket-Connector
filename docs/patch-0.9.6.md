# 0.9.6：统一手机与电脑界面

电脑连接器和 Android App 使用同一套蓝灰配色、圆角、边框与状态层级。

- 电脑端：深色步骤栏，三种连接方式独立展示；窄窗口自动改为横向卡片。重做连接、配对二维码、表单、诊断页和配对管理页的样式。
- 手机端：重新设计公网、局域网、自建中继入口；强化项目分组、新建对话与电脑切换入口，统一浅色和深色主题。
- 对话：工具记录使用完整内容宽度，终端输出保持可展开；输入框在获得焦点时显示蓝色边框，发送按钮与其他操作统一。模型和权限文字增大，键盘弹出后仍优先展示输入内容。
- 可访问性：保留主要操作至少 48dp 的触控区域，桌面键盘焦点可见，尊重系统减少动画设置。自建服务填写错误时，将错误提示滚动到可见区域。

此次参考 [Uiverse Galaxy](https://github.com/uiverse-io/galaxy) 的卡片层级、图标与按钮反馈方式，以项目现有 HTML/CSS 和 Jetpack Compose 实现。没有直接复制其中的组件源码，没有引入新的 UI 依赖。

Android versionCode 为 24，使用原签名覆盖安装。电脑与手机安装包统一为 0.9.6，沿用原公网服务配置；无需升级中继。
