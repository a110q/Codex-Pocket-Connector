# 0.9.15 验证记录

2026-11-02，公开版本 0.9.15，构建号 43。

后续真实验收发现本版项目移除修复仍有遗漏：桌面可见清单与底层项目表不一致。以下项目测试结果仅代表其列出的测试场景，完整修复及真实清单验证见 [0.9.15.1 验证记录](verification-0.9.15.1.md)。

## 实现与验证

- 图片：为 CommonMark 图片节点保留原位置的图片标记，以原生文本图片跨度加载和绘制，避免拆分 Markdown 破坏编号、引用及表格。电脑文件仍由 FileAccess 检查会话、路径和文件版本；本次没有扩大本地文件读取权限。远程图片请求不携带应用账号令牌、配对信息或 Cookie。图片解码采样，最多两个并发请求，单图最多 50 MB，缩略图缓存有大小上限。
- 折叠：交付卡片标题可点击且有折叠状态说明；内容默认隐藏，实时消息刷新保留选择，状态按会话隔离。
- 项目：完成迁移后以当前项目表判断存在性，不再合并已经移除但残留在旧 JSON 中的项目。连接器读取 project/list 时以返回列表决定项目是否存在，保留仍存在项目的旧 ID 别名；名称和根目录采用新值。手机前台每 5 秒刷新，重复请求合并，断线或切换电脑时旧请求失效；请求失败保留缓存。
- 滑动：三个筛选页使用 HorizontalPager，点击和滑动共享页面状态，列表保留竖向滚动。预加载页的内容不重复出现在可访问性树中。

## 测试

- Node 全量 203 项通过，其中新增已移除项目、空项目列表、旧 ID 别名与改名路径回归。
- Android JVM 33 项通过。
- 中文 Android 模拟器 13 项相关测试全部通过：真实加密文件通道中的正文图片及点击预览；列表、引用式图片、表格图片与代码示例；图片失败重试；网络图片离线缓存及请求无账号凭据；交付卡片折叠和展开；不重新进入、不手动刷新时同步项目改名、移除及清空；滑动与点击筛选；原有状态筛选；历史分页与表格回归。
- 首轮 13 项测试中有两项失败：图片测试错误依赖 getSpans 的返回顺序，改为按文本位置验证；滑动预加载页暴露了重复可访问性内容，修复屏幕外页面语义后复测。复测 13 项全部通过，首轮结果一并保留。
- Android 正式 APK 安装成功，版本 0.9.15 / 43，冷启动正常。APK 使用现有发布签名，验签通过。
- Mac、Windows、Android 使用项目约定命令打包，均成功。Mac codesign 校验通过，Windows ZIP 完整性及打包源码一致性校验通过。每个平台保留本版和 0.9.14.1。
