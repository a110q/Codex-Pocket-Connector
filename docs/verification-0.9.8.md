# 0.9.8 验收记录

## 真实长会话读取

在实际出现故障的会话上进行只读探测，不发送测试消息、不修改会话内容。会话含 6,000 多条手机可见记录，桌面快照约 44 MB。

| 场景 | 结果 |
| --- | --- |
| 修复前，连续三次读取 | 30.1、17.9、34.0 秒；均回退到存储历史，未及时取得实时状态 |
| 修复接收与补丁处理后 | 0.94、0.90、0.97 秒；均取得桌面实时状态 |
| 加入持续订阅复用后 | 首次约 1.08 秒；后两次约 1 毫秒，不重复下载完整历史 |
| 完整加密链路：测试中继 → 真实电脑 → 手机协议客户端 | 首次约 1.12 秒，返回最近 40 / 6,155 条记录；再次读取约 11 毫秒 |
| 向前翻页 | 另外 40 条记录，与当前页不重叠；完整历史仍可访问 |
| 完整链路最大加密帧 | 168,628 字节；没有将 44 MB 原始快照直接发送到手机 |

完整链路测试使用本机隔离 TLS 中继与协议客户端，不能代表用户移动网络的实际延迟。计时会随机器负载与会话内容变化。

## 真实发送与追加

仅在用户授权的独立验收会话中发送。测试代理在桌面快照中附加 44 MB 合成历史负载，原始桌面状态和用户项目不受修改。

- 首次发送约 262 毫秒，运行中追加约 4 毫秒。
- 桌面实际收到 1 次开始请求、1 次追加请求，两条消息均通过独立客户端消息 ID 查询确认。
- 收到预期最终回复。连续 24 个补丁正常处理，文字更新不会各自触发一次完整历史请求。
- 验收结束后重新归档测试会话。
