# 0.9.15.4 更新

版本 0.9.15.4，构建号 47。日期：2026-11-02。本轮发布三端安装包与签名更新清单，沿用原有中继及分发编排。

## 运行任务无需进入对话才显示

电脑连接器独立启动时，桌面 App Tools 会拒绝读取任务摘要。此前在 Codex 内置终端执行的测试具有不同的进程来源，不能证明独立 App 正常。这是运行任务遗漏及进入对话后才出现标记的关键原因。

改为通过现有桌面 owner/follower IPC 同步通道预热任务状态。持续跟随已加载会话的状态变化，保留运行状态和审批标记，不保留聊天历史内容；按完整本地目录发现会话，覆盖前 50 个以外的任务。监听不会调用 thread/resume 或取得对话写入权。首次订阅仍会收到桌面协议的会话快照，接收后仅保留状态字段；后续只处理状态增量。手机离线时也持续预热，重新连接的 hello 携带状态，变化主动推送。手机列表轮询仍作为后备。

## 历史加载失败

后台轮询和其他对话更新可能挤掉正在阅读的会话缓存。加载更早记录或长消息时，缓存缺失会自动重新读取会话，并沿用分页位置继续加载；同一会话的并发恢复共享读取，不再要求用户退出重进。缓存上限保留。

## 确认问答显示混乱

完整合法的 send_user_message_question_reply 包装转为问题和回答卡片，不再把内部 XML、JSON 与调用 ID 展示在正文。手机兼容旧缓存内容，普通文字、代码引用和不完整包装保持原意。原始记录仍可用于详情，不改写用户历史。
