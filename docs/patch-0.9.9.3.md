# Codex Pocket 0.9.9.3

修复手机把历史命令的非零退出重复显示成大块“执行失败”告警的问题。本版包含 0.9.9.2 的历史分页、本地 HTML 和 Markdown 表格修复。

## 命令结果与任务状态

- 删除回复末尾重复展示的命令失败卡片。查询、搜索或检查命令返回非零，不再被提升为整个任务失败。
- 执行过程仍可展开，保留原始命令、输出、退出码和完整详情。未成功的记录使用中性的摘要提示，不丢弃错误信息。
- 运行中的工具优先展示运行状态；拒绝和取消分别显示。
- 只有电脑报告当前任务出错时，才显示一条任务错误提示。恢复运行后提示消失，历史记录仍保留。

## 同时包含的修复

- 向上滚动到聊天顶部附近时自动加载更早历史，保持可见消息的位置。阅读期间的新回复不会强制跳到底部。
- 点击聊天或项目文件树中的本地 HTML，在 App 内交互预览，支持 CSS、JavaScript、图片及 JSON 相对资源，复用现有加密通道。
- Markdown 表格按行列显示，宽表格单独横向滚动，保留单元格格式和链接。

详情见 [0.9.9.2 修复说明](patch-0.9.9.2.md)。

## 安装

手机和电脑连接器均更新至 0.9.9.3；新增的本地 HTML 功能需要新版电脑连接器。中继无需升级，默认公网服务配置保留。

- Android：`releases/android/Codex-Pocket-0.9.9.3.apk`，内部版本号 35，原签名覆盖安装。
- Mac：`releases/mac/Codex-Pocket-Connector-0.9.9.3.app`，本地签名，尚未 Apple 公证。
- Windows：`releases/windows/Codex-Pocket-Connector-0.9.9.3-Windows.exe` 或同版本 ZIP，尚未代码签名，仍待 Windows 11 实机连接验收。

本地安装包不等于已发布 GitHub Release。公开下载链接仍保持指向已发布的版本。
