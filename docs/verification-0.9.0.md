# 0.9.0 验证记录

日期：2026-10-25。开发和交付文件均保存在项目内。测试使用隔离 TLS 中继、虚构账号/文件、临时 Git 仓库和 Android 模拟器。真实 Codex 变更仅涉及先前获准的专用验收对话重命名，并恢复原名称；未修改用户工作对话、真实插件/技能或生产中继。

## 自动化与实际连接

- 135 项 Node 测试通过，生产依赖审计无已知漏洞。
- 文件树测试验证分页、名称搜索、隐藏私有目录、拒绝路径越界/符号链接、分块完整性和文件变化检测；项目引用仅解析实际项目内文件。
- 在临时真实 Git 仓库验证分支/状态、暂存/未暂存差异、带空格文件、修改过期拒绝、选择文件提交、暂存区夹带拒绝以及向本地上游推送。PR 参数与草稿模式通过隔离执行器验证，未向真实 GitHub 仓库创建测试 PR。
- 定时任务验证持久化、到期单次执行、暂停/编辑/删除/立即执行、时区/工作日、启动失败历史以及重启不重放未知操作。执行提交使用隔离适配器；没有创建真实持续运行的定时任务。
- 技能/插件写入路由和约束、用量错误与实时/本地 Token 来源、OAuth 完成通知、标准/嵌套表单及对象审批通过测试。真实 Codex 只读连接成功读取技能与已安装插件。
- 专用验收对话的 `thread/name/set` 持久化及桌面目录同步实际确认，并恢复名称。测试也发现原桌面目录存在已归档验收对话的旧缓存；重命名现按真实归档状态刷新，避免将归档对话误显示为活动对话。
- 当前电脑独立 App Server 的额度/账号统计接口实际返回需要账号认证；界面保留原因，未将缺数据填成零。Token 数据只取实际实时事件或 Codex 会话文件中的 token_count 统计，不返回原始会话日志。
- 17 项 Android JVM 测试通过。按类别合并 46 项安卓原生测试通过，涵盖新功能及账号、配对、恢复、图片/文件发送、后台通知、预览、设置、扫码退出等旧功能。
- 360dp 小屏下运行工具、文件/Git、用量、表单和旧界面回归；检查实际截图。恢复模拟器默认密度。debug lint 通过，release APK 覆盖安装并成功启动。
- 真实 Docker/第三方账号的 SelfHostingFlowTest 本轮未提供专用环境参数，明确跳过 1 项；隔离中继及加密协议测试通过。不同第三方 OAuth 服务的真实授权尚未逐个验证。

## 安装包与发布

- 手机与电脑版本统一为 0.9.0；Android versionCode 为 18，与上一版使用同一签名。
- Mac APP 的 arm64/x86_64 架构及签名检查通过；Windows EXE/ZIP 构建、内容清单和 ZIP 完整性检查通过。新增模块与其依赖均已纳入桌面包。
- 每个平台仅保留 0.8.0 和 0.9.0。安装包保留预设公网服务；公开源码替换个人公网配置，敏感资料保留在 `.private`。发布前检查源码、APK、APP ZIP、Windows EXE/ZIP，不含 root/管理员密码、私钥或配对密钥。
- 本版不改变中继 API，无需升级生产服务器。

## 仍有的限制

Windows 11 尚无实机连接验收；静态检查和打包成功不能替代该验证。Mac 为临时签名且未 Apple 公证，Windows EXE 未代码签名。

官方桌面定时任务的管理接口不向此独立客户端开放，Pocket 任务需连接器持续运行。OpenAI 专用身份验证/专用输入控件仍保留电脑完成路径。部分插件需官方安装告知或受账号/组织限制。PR 需要已登录的 GitHub CLI；用量需要账号接口支持。未宣称所有第三方授权、安卓厂商后台策略或所有 Codex 桌面版本均已通过。

公开接口参考：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。详细用法和功能边界见 [0.9.0 更新说明](patch-0.9.0.md)。
