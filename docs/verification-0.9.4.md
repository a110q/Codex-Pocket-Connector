# 0.9.4 验证记录

日期：2026-10-26。Android、Windows、macOS 统一版本 0.9.4；Android versionCode 22。

## 本次验证

- 工作源码与脱敏公开源码的 Node 测试：各 147 项通过。
- Android JVM：17 项通过。
- 原生模拟器：聊天界面 8 项、账号流程 6 项，共 14 项通过。
- lintDebug：0 错误、27 条现有警告。

- Mac APP 签名与文件完整性通过；Windows ZIP 的 925 个文件哈希逐一匹配，包含最终中继逻辑。

## 网页

原生点击测试先复现了聊天链接没有打开。原因是文本选择给 TextView 设置了移动处理器，拦截了链接触摸。修复后保留文本选择，并显式处理链接点击；普通网址也使用 Markdown 的同一链接回调。

测试真实点击 Markdown「点击打开」及普通 HTTP 地址，经过加密手机/电脑协议与 TCP 预览代理加载测试网页。除了确认收到请求，还读取 WebView 的页面文本，确认网页已实际渲染。覆盖 `127.0.0.1`、展开后隐藏输入区、缩回小窗、收起后再次点击同一链接、关闭后再次打开、系统返回键回到聊天布局。

测试网页与协议服务属于隔离夹具；没有操作用户的项目或聊天。本轮没有复现截图中的项目页面空白，不能把所有网站加载问题都归因于链接触摸。加载超时现有明确提示及重新建立预览的入口。

## 指定电脑移除

服务端测试覆盖普通用户无管理权限、跨账号电脑拒绝、管理员必须选择具体电脑、管理员手机继续受保护、选中电脑凭据撤销、重复删除返回错误。移除一台管理员电脑后，另一台的真实 WebSocket 仍保持打开并可交换心跳。

Android 通过 AccountApi 连接独立运行的实际中继代码，验证用户中心取消确认、移除普通用户的指定电脑、移除管理员自己的指定电脑、保留其他绑定及管理员登录。没有删除线上真实设备。界面用电脑 ID 识别操作对象，名称仅作展示。

账号回归包含申请审批、角色菜单、安全提醒、停用、局域网使用、手机发起公网配对、加密存储及签名读取。

## 发布隐私

公开源码与安装包共扫描 3138 个文件、展开 5 个归档，未发现已知服务器 root 密码、管理员密码、开发配对凭据或个人绝对路径。安装包按要求保留预设公网配置，公开源码继续脱敏。

## 部署与限制

预设中继已更新到 0.9.4。升级先冻结数据库写入并备份，保留旧容器和失败回滚；升级前后账号、手机与电脑身份表摘要一致。外部 HTTPS 健康检查返回 200，包含 `deviceRemoval: selected-v1`。没有更改真实账号、配对或设备绑定。

自建中继需要同步更新源码并重新构建部署，才能使用管理员移除自己电脑及只断开所选电脑的逻辑。

本轮只回归与变更相关的原生用例，没有重跑历史所有 Android 测试。Windows 11 仍待实机连接验收。截图来自 360dp 宽度的 Android 模拟器和隔离测试数据；不是用户真实项目。
