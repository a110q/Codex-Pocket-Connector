# 0.9.17.8｜缩短手机删除同步等待

- 手机确认后仍由配对电脑立即尝试原生删除；电脑确认后才同步移除，不把尚未删除的对话在手机上隐藏。
- 电脑连接恢复、收到对话释放信号或任务结束时，优先检查关联的待处理操作。没收到信号时，首次后台重试从 2.5 秒缩到 0.5 秒，后续间隔最多 3 秒。这是调度间隔，不是 Codex 执行删除的耗时承诺。
- 一条对话等待核实不再阻塞其他对话的后台处理；同一对话仍按顺序操作，已发送但回执不明的请求只读回核实，不重复提交。
- 安卓区分「电脑暂时占用，待删除」和「正在确认删除结果」。如果电脑端一直不释放对话，仍无法立刻删除。

## 验证范围

用独立的 Codex 数据目录验证外部占用、连接器重启后继续处理、释放后实际删除、其他对话不受影响。Node 回归测试覆盖释放信号提前唤醒、三秒重试上限、多个对话独立核实。Windows 安装包完成构建和完整性检查，未做 Windows 实机连接验收。

本轮 Node 回归 238 项通过，安卓中文模拟器对话状态回归 15 项通过，APK 签名与上一版相同。隔离 App Server 实测：释放外部进程并完成读回约 1 秒（单次测量）。
