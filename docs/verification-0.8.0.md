# 0.8.0 验收记录

日期：2026-10-25。使用隔离 TLS 中继、虚构账号/文件，以及 Android 模拟器；未操作个人工作对话或升级生产中继。

## 自动化验证

- 121 项 Node 测试通过，包括真实加密 WebSocket 文件/图片分片传输、消息去重、SHA-256 完整性、断点恢复、跨对话拒绝、文件访问范围、原生本地附件引用，以及新建与继续对话的输入格式。
- 权限测试验证不能授予未请求的路径/网络、扩大扫描深度或去掉禁止条目；MCP 验证必填、类型、选项、数量/长度/数值范围及常见格式。身份验证与复杂 schema 明确拒绝在手机接受。
- 扩展审批已核对实际桌面协议方法及响应封装；自动化验证 IPC 路由、过期请求、独立 App Server 响应及请求消解。未对真实第三方 MCP 账号执行授权。
- 16 项 Android JVM 测试通过，覆盖提醒状态转换、去重、历史完成记录不误报、失败与中断区分，以及现有草稿、历史合并和预览逻辑。
- 35 项安卓原生流程按类别验证通过；账号和配对类在全新隔离中继重跑。覆盖账号角色、申请审批、局域网/公网配对、连接恢复、三个入口与返回、服务隔离、图片与文件发送、预览、模型设置和扫码关闭。
- 新增文件测试实际导入 410 KB 文件，经多段加密消息接收，核对全部字节、文件草稿恢复与单次发送。审批页验证逐项缩减权限、会话作用域、整数表单及不支持的身份验证提示。
- 后台服务测试使用实际 Android 前台服务、TLS WebSocket、加密事件与通知：后台完成通知、重复事件去重、通知跳转到原对话、恢复前台避免重复连接、关闭服务和自建中继账号停用后拒绝监视。后台连接只发读取请求。
- debug lint、release 构建检查通过。新增页面在 360dp 宽度检查，文档截图来自虚构测试数据。

## 交付包

- 版本统一为 0.8.0。Mac APP 包含 arm64 与 x86_64，签名校验通过；Windows EXE/ZIP 构建及归档完整性通过。
- Android release APK 与上一版签名保持一致，可覆盖安装；公开附件同时提供 SHA-256 校验值。
- 新增电脑模块已纳入两种桌面包；安装包保留预设公网配置。源码与发布附件检查不含服务器 root 密码、管理员首次登录资料、SSH/签名私钥和个人配对资料。
- 本版中继协议不变，无需迁移生产数据库。每个平台保留最近两个版本。

## 验证边界

Windows 11 仍待实机启动与连接验收；构建成功不代表实机验收通过。Mac 为临时签名，未 Apple 公证；Windows EXE 未代码签名。

后台提醒通过安卓前台服务维持加密连接，不是系统级云推送。系统强行停止、厂商省电、网络限制或电脑睡眠可能延迟或中断提醒；模拟器结果不代表所有安卓厂商。仅监视当前连接模式/中继中已批准配对的电脑。

普通文件通过电脑侧受控目录和 Codex 的本地文件引用格式送达；具体格式的内容理解取决于 Codex 与相关工具。复杂 MCP 表单、需电脑完成的身份验证、完整终端等仍未覆盖。
