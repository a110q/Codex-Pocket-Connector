# 0.7.8 更新说明

- 手机首页搜索默认收起，顶部保留搜索、新建对话和更多菜单；已归档、任务动态与刷新移入更多菜单。
- 去掉固定底部大按钮，精简项目标题与对话留白。保持 14sp 对话字号、48dp 点击区域及展开搜索框高度。
- 手机运行的会话通过本地桌面 IPC 提供所有者发现与完整快照，电脑可跟随同一任务，并提交普通文字/图片、停止任务、处理受支持的审批及调整下一轮设置。
- 持续检查空闲会话，不再在少量重试后放弃释放。运行中、有待处理审批或桌面仍在跟随时保留进程；桌面离开后自动释放。
- 打包时保留安装包原有服务配置，公开源码继续脱敏。

电脑与安卓客户端都更新至 0.7.8。升级前已显示的占用提示需要点一次「重试」。本地桌面 IPC 是非公开接口，后续 Codex 版本可能需要适配；不支持的版本或操作会明确拒绝。远程主机、部分高级审批与 App Tools 投递不属于此次新增桌面跟随支持。

验证范围见 [验收记录](verification-0.7.8.md)。Windows 11 仍需实机连接验收。
