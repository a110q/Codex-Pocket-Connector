# 0.9.7：桌面对话发送恢复与局域网换网修复

手机能连上电脑，但发送时反复提示“对话由电脑 Codex 持有”，可能发生在桌面控制连接失效的情况下。公网、局域网、自建中继共用这段链路，因此都需要更新电脑连接器。

- 桌面拒绝第二个会话写入进程后，连接器会有限次重新发现原会话控制者，必要时重建空闲的本地连接。已有请求等待回执时不会强制断开该连接。
- 修正业务请求误用 2.5 秒建连超时的问题，使用各请求自己的响应时限。
- 恢复只重试查找连接；已经提交但回执不明确的消息继续查询回执，不自动重发，不抢占原会话写入权。
- 自动恢复仍失败时，区分响应超时、本地连接断开、对话控制者不可用，并明确保留草稿。
- 局域网地址变化或证书过期时自动更新证书，保留电脑身份和授权资料，直接进入二维码流程；地址已变化的手机需重新扫码。
- 连接方式的高亮跟随实际选择。切换到公网或自建中继时收起局域网地址，公网配对页不会残留局域网提示。

三端版本统一为 **0.9.7**。本次 Android 仅同步版本号，关键修复在电脑连接器；中继无需升级。已有有效配对继续使用；已被服务器撤销的电脑绑定需要重新扫码。
