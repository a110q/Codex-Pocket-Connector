# Codex Pocket 0.9.10

新增 Android 和电脑连接器的“检测更新”。对外版本 0.9.10，内部构建号 36；包含 0.9.9.3 的全部历史分页、本地 HTML、Markdown 表格和命令结果展示修复。

已于 2026-10-30 发布到自建更新服务器，三端安装包及签名 stable 清单已上线。本次未发布 GitHub Release。0.9.9.3 及更早版本需要先手动安装 0.9.10，之后具备应用内更新入口。

## 使用入口

- Android：设置页底部的“检测更新”；选择连接方式和公网登录页也提供入口，未登录时可用。
- Mac / Windows：电脑连接器左下角“关于与更新”。

页面展示当前版本、最新版本和更新说明。检测失败时明确提示并可重试，不会误报“已是最新”。用户点击后才下载，显示进度并验证文件。

Android 下载后同时验证 APK 包名、版本、构建号及当前应用签名。点击“安装更新”，按系统要求授权本应用安装，再进入系统安装页面确认。覆盖安装保留现有应用数据。

Mac 下载 ZIP，校验后打开 Finder 中的下载位置；解压，退出旧连接器，再把新 App 移到应用程序目录。Windows 下载 EXE，校验后打开 Explorer 中的文件位置；退出旧连接器后启动新版。使用相同应用及用户数据目录时保留原账号与配对信息。

## 更新验证

更新请求独立于配对和账号服务，不携带账号 Token。客户端校验服务器公开证书及主机名，再验证 Ed25519 签名清单；下载地址限于同一 HTTPS 来源，禁止跳转，按签名清单核对文件大小和 SHA-256。安装或打开下载位置前再次验证文件。失败的未完成文件会清除，可以重试。

三段和四段版本均逐段按数字比较，另要求新版本构建号递增。不会自动替换正在运行的连接器，也不会强制中断任务。

部署准备和版本发布流程见 [更新分发维护说明](UPDATES.md)。验证结果见 [0.9.10 验证记录](verification-0.9.10.md)。
