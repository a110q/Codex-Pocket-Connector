# 0.9.2 验证记录

日期：2026-10-25。三端统一版本 0.9.2，Android versionCode 20。

## 结果

- Node：工作源码与脱敏公开源码均 142 项通过。
- Android JVM：17 项通过。
- 原生 Android：70 个不同用例，66 项通过、4 项跳过，无失败。多电脑与连接恢复 17 项通过；其余回归含界面补测 56 项，其中 3 项与前一批重复。
- Android lintDebug：0 错误、27 条现有警告；没有关闭证书固定或主机名校验。
- Android 模拟器：1080×2400、密度 480（360dp），已查看下拉菜单、重命名弹窗和保存后的实际截图。

4 项跳过为：3 项需要显式提供真实 Codex 只读环境的工具页验收、1 项需要专用自建公网服务器的完整图文任务验收。本轮已通过隔离真实中继的账号注册、审批、配对与路由测试；未把跳过项算作通过。

## 本次缺陷与覆盖

发送后切到后台时，旧连接的回调会被丢弃，界面 busy 状态无法清除。先用生命周期测试复现失败，再确认修复通过。现已覆盖后台恢复、连接替换、确认响应丢失、只读回执查询、未知请求不重发，以及 A/B 电脑各自草稿与待确认记录隔离。

设备操作覆盖顶部下拉切换、名称验证和持久化、重新扫码保留别名、通知采用新名称且不重启无关连接。后台多电脑提醒、重复审批隔离、通知点击切换、账号失效拒绝监控均通过。

电脑改绑覆盖真实隔离中继：旧凭据撤销、旧连接退出、新二维码生成、目标账号确认、响应丢失后重试复用，以及 403/网络/TLS/服务器错误不重置身份。回执验证核对请求动作与参数，确认查询不会执行缺失操作。

其余回归覆盖聊天、项目搜索、输入法与发送按钮、图文与文件附件、模型/权限、审批、扫描关闭、预览、工具页及轮询队列。全部使用隔离数据，不创建或修改用户聊天。

公网中继三次即时健康检查均 HTTP 200，耗时 228 / 325 / 312 ms；这些结果只反映检查时刻，不能证明历史网络始终正常。
