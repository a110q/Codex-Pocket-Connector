# Codex Pocket 0.9.9.2

本次修复聊天历史和本地审核页面的手机体验。手机 App 与电脑连接器需要一起升级；中继协议兼容现有服务，无须修改公网服务器配置。

## 聊天历史

- 进入聊天仍定位最新内容；向上滚动到顶部附近时自动加载上一页，不再反复点击按钮。
- 加载时保留可见消息的位置，折叠工具组跨分页也保持身份和展开状态。
- 阅读历史期间，新回复不拉回底部；可点右下角箭头回到最新。
- 加载失败在历史区域提供重试；切换会话、电脑或断开连接后，旧分页响应不会污染新会话。

## 本地 HTML 审核页

- 支持助手回复中的相对路径、文件 URI、编码空格和编辑器行号后缀；Windows 路径按电脑原生格式解析。
- 点击 HTML/HTM 文件进入 App 内网页预览，支持相对 CSS、JavaScript、图片、字体和 JSON 资源。
- 项目文件树中的 HTML 使用相同预览方式。网页刷新重新取得有效的文件预览地址。
- 页面和资源经过现有加密预览通道传输，公网使用无需把项目目录暴露到局域网或公网端口。
- 预览仍受项目和当前会话的文件授权限制。隐藏文件、越界路径、越界符号链接和非网页资源被拒绝；文件已移动或电脑端过旧时给出明确提示。

## Markdown 表格

表格按行列展示，保留单元格中的链接和文字格式。宽表格单独横向滚动，正文维持手机屏宽。

## 安装

- Android：覆盖安装 `releases/android/Codex-Pocket-0.9.9.2.apk`。
- Mac：打开 `releases/mac/Codex-Pocket-Connector-0.9.9.2.app`。
- Windows：运行 `releases/windows/Codex-Pocket-Connector-0.9.9.2-Windows.exe`，或解压同版本 ZIP 后打开其中的 EXE。

Windows 仍需 Windows 11 实机连接验收。Mac 使用本地签名，尚未 Apple 公证。
