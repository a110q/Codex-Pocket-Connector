# 0.9.17.2 验证记录

日期：2026 年 11 月 19 日。对外版本 `0.9.17.2`，构建号 `52`。

## Windows 本地数据目录

- 旧版将创建目录、读取权限和设置权限合并在 `STATE_DIRECTORY` 阶段，截图里的 `0x80070005` 无法单独确定是哪一步被拒绝。在 Windows 11 虚拟机用非提升权限的 Windows 账户复现了一条路径：目录私有且可写，但禁止重复改权限，旧版 `Set-Acl` 报 `0x80070005`。
- 新版原地使用已验证为私有且可写的目录。首次创建即使用私有访问控制；现有目录只有在权限不符合要求时才修复访问控制并重新验证。不换目录、不拿所有权、不删除或重置配置。无法安全使用原目录时直接停在启动前，分别报告路径、创建、权限读取、权限修复、复核或写入检查。诊断编号不包含账号或配对数据。
- `test/windows/state-directory.ps1` 的 7 项 NTFS 回归均通过：首次启动、旧版权限拒绝而新版复用原数据、目录不可写、不安全权限修复并收紧现有文件的继承权限、不安全权限无法修复时阻止启动、路径被文件占用、拒绝目录联接。测试已接入项目的 Windows CI 配置。
- 在中文 Windows 11 ARM64 虚拟机、普通权限下实际运行单文件 EXE 和解压后的免安装 ZIP。两者都加载了 WebView2 中文连接界面、返回 `0.9.17.2` 的本机 API 响应，关闭窗口后后台退出。ZIP 从禁止改权限的既有测试目录启动，原配置保留。未在用户的 Windows 电脑上运行，也未在此次测试中进行账号登录、手机配对或跨端操作验收。
