# 0.9.15.4 验证记录

日期：2026-11-02。版本 0.9.15.4 / build 47。本记录编制于本地验收阶段，随后用户授权正式发布；线上发布结果以 GitHub Release 和签名稳定清单为准。

## 真实环境

独立 Mac App 0.9.15.3 的诊断持续出现 runtime.unavailable；对实际运行进程的定向检查得到「App tools require bundled Node launched by the running desktop app」。清空对话环境变量的内置终端进程仍能读取工具，说明仅删除环境变量不足以复现独立 App 的进程来源。旧工具 socket 残留也影响自动发现，已补充监听探测，但该修复本身不足以解决 App Tools 的来源限制。

最终版本使用已有 desktop IPC 的 owner/follower 协议获取运行状态。先在实际 IPC 验证 snapshot v11 的 threadRuntimeStatus，再实现只保留状态的投影。首次订阅当前长对话收到约 15 MB 快照，历史正文在解析后丢弃；因此不能描述为桌面只传输摘要。随后 12 个已加载会话仅保留约 2 KB 的监听状态；排除子代理后只跟随可见本地会话。增量修订、activeFlags、丢帧重同步、断线和取消监听有独立回归。

本机独立启动最终 Mac App，未继承工具管道或聊天上下文，日志确认 10 个状态、4 个实际运行任务，与当时桌面任务一致，runtime.unavailable 为 0。切换后 connected=true、mobileOnline=false、error 为空；配对身份摘要一致，旧窗口及旧后台均已关闭。这不代表用户实体手机已连接验收。

真实原始对话包含 3061 条记录、4 组确认问答。先读取 40 条，再用 8 个其他会话挤掉缓存，随后自动恢复更早 40 条，记录连续、无重复，恢复用时 146 ms。测试对话包含 52 条独立编号消息、表格、两张图片和确认问题。
