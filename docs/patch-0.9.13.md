# 0.9.13 本地试用版

本次重点调整 Android 的聊天与对话列表，延续 Codex Pocket 的紫蓝配色和原生交互。

- 工作空间新增「全部 / 运行中 / 待审批」筛选及实时数量，支持与项目、对话搜索组合使用。等待输入与待审批分别判断；断线显示上次状态。
- 聊天顶部统一显示对话状态。移除普通消息的重复同步回执，以及回复栏的重复同步、流式输出标签；排队消息仍保留完整排队提示。
- 执行过程改为轻量摘要，保留记录数量、未成功记录提示与展开入口。命令返回非零不等于任务失败。
- 聊天直接显示最多三个交付文件，包含名称、类型、大小和预览入口。可继续查看全部文件、保存到手机。
- 展示最近一轮真实代码修改的路径与增删行数；数据截断时提示部分内容，隐藏不完整行数。完整修改仍可从交付与修改页面查看。
- 电脑绿点仅表示已连接，断线时明确提示连接状态。审批命令、目录、允许和拒绝按钮完整保留，排在交付结果之后。

版本：0.9.13，构建号：40。仅生成本地试用包，未推送 GitHub、生产中继或在线更新渠道。
