# 0.9.5：修复公网首次加载网页白屏

Android、Windows、macOS 统一为 0.9.5。请同时更新手机 App 和电脑连接器。

大型 Vite 等开发页面首次打开时，需要下载较多脚本。0.9.4 未压缩网页转发数据，并且在 30 秒后停止仍在加载的页面；公网带宽受限时可能留下白屏。已有缓存的页面和小型测试页不一定出现这个问题。

- 电脑端按手机请求压缩转发数据，手机还原原始 TCP 字节；网页、证书校验、Cookie 和 WebSocket 的处理方式不变。
- 压缩只在确实减少流量时启用。新旧端兼容，但两端都更新后才会使用压缩。
- 手机显示已接收数据量；持续加载的页面不再被固定 30 秒计时中断。
- 45 秒没有新数据或总加载时间达到 3 分钟时，明确提示重试。建立连接也有独立超时。
- 点击刷新或重新打开会重建预览连接；主页面连接失败时显示电脑返回的原因。

本次修复发生在手机和电脑端，中继无需升级。测试覆盖公网中继与真实本地开发页面，但页面本身的错误、停机和手机网络变化仍可能影响访问。
