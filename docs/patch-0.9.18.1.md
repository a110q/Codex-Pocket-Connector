# 0.9.18.1 项目与会话归属同步修复

手机项目列表和会话列表可能分别使用同一个项目的新、旧 ID，造成电脑项目中的会话在手机上被误放到“独立对话”。本次统一两端返回的项目标识，并让 Android 识别桌面明确提供的 ID 映射。

- 保留电脑当前返回的项目、顺序和空项目，已移除的项目不会因旧记录残留而重新出现。
- 项目折叠时收到新会话，展开后仍显示在对应项目中。
- 修正 Android 处理 JSON 空项目 ID 时的误匹配，已移出项目的会话保持独立。
- 项目内新建对话时，将手机使用的稳定 ID 转换为当前桌面实际接受的 ID。
- 不按会话标题或工作目录猜测项目归属，避免同名会话和不同主机之间错误合并。

版本号为 `0.9.18.1`，构建号为 `63`。此次修改涉及电脑连接器与 Android 客户端，升级时需同步更新。

本地已通过 255 项 Node 测试、33 项 Android 单元测试及 29 项 Android 14 模拟器界面测试。尚未生成本版本正式交付包、发布 GitHub 或部署更新服务；客户 Windows、自建中继和手机实机组合仍待验收。
