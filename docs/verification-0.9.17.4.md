# 0.9.17.4 验证记录

对外版本 `0.9.17.4`，构建号 `54`。

- 修复 Windows 某些管理员运行环境首次创建本地数据目录时，系统默认把所有者设为管理员组、继而被连接器拒绝的问题。仅新建目录时显式设当前用户为所有者；已有目录仍执行原有所有者和权限检查，不接管其他账户的目录。
- GitHub Actions 的 Windows 测试通过：新建目录所有者和访问权限、已有状态保留、不可写目录、权限修复、受保护目录、文件占位及目录联接处理；Windows 连接器入口的目录别名及错误诊断测试也通过。Linux Node 22 运行全部 232 项测试通过。本机 232 项 Node 测试通过。
- Windows ZIP 的文件哈希和 EXE 内嵌内容一致性已校验；macOS App 本机启动和严格临时验签通过；Android APK 签名已验证，与上一版保持同一签名证书，versionCode 为 `54`。
- 共享路径启动及跨端对话操作的集成验证范围见 [0.9.17.3 验证记录](verification-0.9.17.3.md)。本版未用 Parallels，不包含新的 Windows x64 实机、独立 EXE 启动或手机真机验收。Windows EXE 未做 Authenticode 代码签名，macOS App 未经 Apple 公证。
