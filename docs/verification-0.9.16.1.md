## 根因与范围

客户报告的 Codex Desktop 26.1111.2228.0 使用 v13 会话流；0.9.16 的会话适配器和独立运行状态读取器均只接受 v11。会话适配器还在校验会话和来源前检查版本，导致无关广播也能触发全局不兼容锁定。

本次接收兼容范围为 v11 和 v13，不自动接受 v12 或未来未知版本。发送给桌面的现有 RPC 和 Pocket 自有会话广播版本保持原值。未知版本若来自正在订阅的真实会话所有者，仍明确拒绝并要求升级，未实现任意协议自动协商。
