# 0.9.8.1 连接恢复、任务状态与执行过程折叠

0.9.8.1 发布版本。手机与电脑连接器需一起更新到 0.9.8.1；本次连接改动无需升级中继。

## 本次定位

- 独立电脑连接器初始化完成时只修改 `ready`，没有发送 `desktop.ready`。手机收到断开通知后，在同一条中继连接上可能一直等不到恢复通知。
- 手机握手、电脑服务启动都会等待 Codex 初始化。初始化慢于手机的 20 秒握手期限时，会出现反复超时；启动界面也不能及时返回。
- WebSocket 心跳只能验证某一端与中继的连接，不能证明手机与电脑之间的加密消息仍能往返。
- 列表返回 `unknown` 或 `notLoaded` 时，曾经确认的“运行中”会被覆盖，造成任务仍在执行但侧栏标记消失。

以上均有隔离测试覆盖。公网健康检查只能说明检查当时接口可用，不能据此排除所有网络或服务器故障。

## 修复行为

- 握手立即返回电脑真实状态；初始化与恢复在后台进行，每 3 秒检查一次。独立 Codex 初始化设置 25 秒上限，超时后可继续恢复；过期初始化结果不能覆盖新连接。
- 电脑恢复后发送就绪通知；手机保留现有中继连接并重新加载项目、对话和回执。
- 新版双方启用加密端到端心跳，每 10 秒探测一次，10 秒未收到对应回复则断开失效连接，随后按原重连机制恢复。旧连接器在尚未就绪时每 5 秒重新确认，避免永远停在等待状态。
- 连接器目录进程初始化失败时，不关闭其他独立运行的对话进程；旧进程的迟到输出不再进入新连接。
- 请求完成后立即取消超时任务；加密与发送顺序统一，减少并发请求产生的乱序风险。关闭连接与处理就绪通知互斥，避免迟到通知把已断开的连接重新显示成在线。
- 不自动重发结果不明的用户消息。保留草稿与操作 ID，重新连接后通过回执检查确认结果。
- 当前电脑连接内记住已确认的任务运行状态；未知摘要保留该状态，明确的完成、审批或错误状态覆盖它。切换电脑或重新握手时清理旧连接状态。

## 手机执行过程

连续的工具调用与思考记录按当前轮次合成“执行过程”，默认折叠。摘要显示记录数、进行中及失败状态；正文回复与待处理审批独立展示。展开后可逐条查看原始记录及完整详情，收起不删除记录。实时新增工具记录不会强制展开，已展开的同组记录保持展开；不同轮次和对话的展开状态分别处理。长执行过程中的单条记录继续使用列表按需渲染。

界面回归还修复了离线时网页地址错误被连接提示隐藏的问题：无效地址的说明直接显示在地址栏下方，保留输入焦点以便修改，不发起网页访问。

## 管理员删除账号

补充管理员删除普通账号的功能，需要输入完整登录账号确认。删除后撤销登录与设备绑定，保留电脑上的 Codex 对话和项目文件。此功能要求中继支持 `accountDeletion: "confirmed-v1"`；自建中继需升级对应代码。连接恢复、运行状态和执行折叠无需为此升级中继。详见 [删除账号说明](account-deletion.md)。

## 更新与版本规则

Android APK 使用原签名覆盖安装，版本名为 0.9.8.1，内部安装版本号为 30。电脑安装包与界面均显示 0.9.8.1。请退出旧电脑连接器后再打开新版，避免两个实例相互接管。

之后每次软件变更都递增对外版本号：小修复使用第四段，功能更新调整中间段，大更新调整第一段。三个平台各保留最近两个版本。内部 npm 版本保持 SemVer；对外版本由 `package.json` 的 `pocketVersion` 提供。Mac 标准三段版本与独立递增构建号兼容平台元数据，完整发行版本另存 `PocketReleaseVersion` 并显示在应用界面。

Windows 为 x64 EXE 与免安装 ZIP，已完成交叉编译和静态完整性检查，尚未在 Windows 11 实机验收。Mac 使用临时本机签名，未进行 Apple 公证。
