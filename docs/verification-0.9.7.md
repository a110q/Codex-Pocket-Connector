# 0.9.7 验收记录

## 桌面发送链路

在用户授权的独立验收会话中，通过本地测试代理模拟“传输仍连接，但原桌面控制连接不响应会话发现”的故障。该代理只影响测试连接，没有修改桌面 Codex 或真实用户会话。

- 0.9.6：复现“这条对话由电脑 Codex 持有，正在恢复桌面连接”的错误，提交次数为 0。
- 0.9.7：重建本地连接后，向原桌面会话提交 1 次，收到预期回复；完整桌面历史中用户消息出现 1 次。
- 自动化回归覆盖：失效连接重建、慢业务响应不误用建连超时、另一条消息仍等待回执时不强制断连、不可用控制者保留草稿，以及既有发送回执与不重复发送逻辑。

此证据确认了可复现故障的修复。用户此前失败时的原始桌面日志未保留，不能据此断言所有历史发送失败都只有同一原因。

## 局域网与界面

- 自动化测试覆盖换网更新证书、保留电脑与手机身份、重复连接复用证书，以及失效地址拒绝写入。
- 在隔离的连接器界面中使用旧网段配置，实际点击局域网连接，成功到达二维码页并显示重新扫码提示。
- 实际切换局域网、自建中继、公网：选中样式正确，局域网地址和提示不泄漏到其他模式。
- UI 场景使用隔离模拟适配器，不计为真实桌面发送验收；真实桌面验收单独记录在上一节。
