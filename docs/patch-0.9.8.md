# 0.9.8：长会话加载与发送修复

修复手机进入长会话时长期停留在“正在读取对话”、发送时等待桌面实时连接、部分操作迟迟无法收到回执的问题。公网、局域网、自建中继共用这段电脑端同步链路，都需要更新电脑连接器。

- 大历史快照改为一次分配、分段接收，避免每个网络分片都复制已有数据；独立 Codex 进程的历史响应也改为线性拼接。
- 正确处理桌面 v11 文字增量：结构化补丁已包含新文本，附带的渲染提示不会再触发重复下载整段历史。
- 补丁只复制变化的路径，连续更新合并显示。完整历史和工具输出仍可分页、展开查看。
- 已持续同步的会话直接复用当前状态；重复或并发打开不会再次订阅完整快照。缺失版本时只发起一次同步，断线或会话控制者变化会清理旧缓存。
- 发送前只读取当前运行状态，无需先补齐全部旧历史。模型与思考强度通过轻量接口确认，相同设置不重复写入。
- 同步失败后不再读取两遍存储历史；未实际提交的消息明确失败并保留草稿，已提交但回执不明确的消息仍查询回执，不自动重发。
- Android 区分不同同步连接的版本序列，桌面重新连接后即使版本从零开始也能更新记录。

Android、Windows、macOS 版本统一为 **0.9.8**。中继不需要升级，安装包保留既有公网服务配置。请同时更新手机和电脑连接器，退出旧连接器后再打开新版。

实测数据与适用范围见 [验收记录](verification-0.9.8.md)。
