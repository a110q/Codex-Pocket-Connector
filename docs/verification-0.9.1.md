## 本轮实际覆盖

- Git：真实临时仓库的状态、差异、提交、推送与过期检查；非仓库、仓库子目录及未安装 Git 的空状态。未对用户项目执行 Git 初始化。
- 工具页：技能搜索与短卡片、技能与插件允许的操作、管理插件的禁用入口、定时任务、会话统计、无效 MCP 授权隐藏及后台接口拒绝。
- 旧功能回归：聊天与搜索、重命名、图片加文字、文件附件、预览、审批表单、模型/权限展示、扫码关闭及断线恢复。
- 多电脑：前台查看 B 时 A 仍提醒；后台两台电脑同时监控；相同审批 ID 按电脑隔离；重复事件去重；点击通知切换电脑并只向目标发送审批；同电脑其他对话复用 UI 连接。
- 连接生命周期：首次配对成功与监控连接交接；切换不重建无关连接；退出取消延迟缓存保存，避免旧页面覆盖新状态。超过 30 个候选对话会轮转，永久不可读的对话不阻断其余对话。
- 真实 Codex 只读验收：通过隔离 TLS 中继连接本机已安装 Codex，读取 18 项技能、4 项由电脑管理的 MCP 服务、真实项目文件及非 Git 项目状态。夹具拒绝所有写操作，没有创建或修改用户聊天及工具配置。
