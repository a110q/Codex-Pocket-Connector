# 0.9.8.2 桌面排队任务同步

修复电脑端任务正在执行时，加入“完成后自动发送”队列的后续指令在手机上不可见的问题。

## 使用效果

- 在手机打开对应对话，能看到已经排队的内容，并标注“排队中 · 当前任务结束后自动发送”。连接前已经加入的队列也会读取。
- 电脑端新增、修改、调整顺序、删除或清空队列后，手机同步更新。服务端队列在打开对话时查询，之后每两秒刷新；桌面客户端队列同时处理实时通知。
- 队列发送后，按消息身份与正式聊天记录去重；相同文字的两次独立提交仍是两条消息。
- 队列暂停、正在发送和发送结果待确认分别显示状态，不自动重发。
- 历史分页、较晚返回的读取结果和连接重建不会重新带回已经删除的排队项。

需要同时更新手机 APK 和电脑连接器到 **0.9.8.2**，退出旧连接器后打开新版。无需升级中继。Android 安装版本号递增为 31，使用原签名覆盖安装。

本次同步用于查看桌面队列，调整和立即发送仍在电脑端操作。只有附件的排队项显示附件数量；不传送队列内部的执行上下文或隐藏指令。

## 实现与验证

原同步层只处理 `thread-stream-state-changed` 聊天记录流，漏掉独立的 `thread-queued-followups-changed` v2 通知及持久化队列。修复补充持久化读取、独立队列通知，以及新版 Codex `thread/queue/list` 只读查询；不会通过读取队列接管对话或启动另一个执行回合。

队列变化有独立版本号，在聊天流版本未变化时也可以拒绝过期队列响应。手机将队列项视为临时记录，加载旧历史不会把已删除的队列项当成历史正文保留。

详细验证见 [0.9.8.2 验证记录](verification-0.9.8.2.md)。Windows 包已打包及静态检查，仍待 Windows 实机连接验收。
