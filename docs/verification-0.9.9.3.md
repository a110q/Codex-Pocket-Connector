# 0.9.9.3 验证记录

日期：2026-10-30。对外版本 0.9.9.3，内部构建号 35。三端安装包已生成，本版本尚未发布 GitHub Release。

## 手机验证

- Node 189 项通过，Android JVM 22 项通过，Android Debug / Release 构建与 lint 通过。
- Android 模拟器回归 48 项全部通过：界面 17、历史分页 4、本地 HTML 加密集成 2、布局与图片 3、连接恢复 19、消息排队 3。
- 在隔离的真实 TLS 中继上，账号与管理界面 7 项全部通过。覆盖注册、批准、登录后的角色菜单、安全提醒、停用、指定电脑移除、账号删除、局域网和公网配对。没有模拟服务端授权响应。
- 合计 55 项 Android 模拟器用例通过，不将模拟器结果等同于用户实体手机验收。
- 新增场景确认：非零退出的历史命令不会产生独立任务失败卡片；运行状态继续显示；原始退出码与详情仍可查看；后续恢复不再显示错误告警；真实任务错误仅显示一条提示，恢复运行后消失。
- 正式签名 APK 覆盖安装成功，冷启动成功，界面显示 0.9.9.3。原签名保持一致，versionCode 为 35。

真实管理员登录曾在 0.9.9.2 正式 APK 上提交，服务器以“账号已绑定另一部手机”拒绝；没有记录为登录成功。用户明确选择保留现有绑定并使用隔离账号验证管理功能，以上 7 项管理验证均在本地测试服务完成，没有解除、停用或修改生产手机、账号及电脑绑定。
