# 0.7.7：自建中继、手机图片发送与配对状态

电脑端、安卓统一更新到 0.7.7，仍使用原签名，保留默认公网服务配置。

## 新增

- 电脑第一步增加「使用自建中继 / 切换服务」，填写 HTTPS 地址并导入公开证书。先验证 TLS、主机名和中继接口，再切换。默认公网仍可直接点击连接。
- 手机登录页可直接扫描电脑配对码。扫描其他中继时先确认服务地址，随后登录或申请该服务的账号。账号、会话缓存、配对和草稿按服务隔离，原服务的 Token 不会发送到新服务。
- 聊天和新建对话支持图片加文字，最多 4 张。可预览、移除；图片缩放到最长边 2048 像素、去除元数据后，通过加密通道分片上传。单张处理后最多 10 MB。

## 修复

- 扫码后立即显示「配对中，等待电脑确认」，正常等待不再显示红色连接错误。临时断网自动继续查询；拒绝、失效和账号权限错误会给出处理提示。
- 临时 steering 消息与正式消息按服务端消息 ID / 客户端请求 ID 合并；刻意发送的相同文字仍分别保留。升级自动重读派生缓存。
- 发送超时或回执丢失时按稳定请求 ID 核对消息是否已送达。确认操作不会重新发送；旧版未保存请求 ID 的模糊超时仍需人工核对，不能凭相同文字推断已发送。
- 修复 Compose 示例临时目录选项的 YAML 写法，避免容器报 `invalid mount path: 'noexec'`。
- Mac 原生窗口支持选择自建服务的公开证书文件。

## 验证与边界

验证记录见 [0.7.7 验收](verification-0.7.7.md)。自建流程使用独立 Docker 中继、独立证书和测试账号，消息仅发到用户授权的专用验收会话。

Windows 提供可运行 EXE 和免安装 ZIP，完成交叉编译及结构检查，仍待 Windows 11 实机连接验收。跨网络使用还受自己的域名、证书、防火墙与网络条件影响。
