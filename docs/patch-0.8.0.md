# 0.8.0 更新说明

- 新增普通文件上传：输入框附件菜单可选图片或文档/代码等文件，普通文件每条最多 4 个、单个最多 50 MB。支持文字、图片和文件混合发送，也可仅发文件；新建对话同样支持。
- 文件草稿按电脑和对话保存；分片上传可断点恢复，并在电脑校验 SHA-256。电脑端使用 Codex 原生本地文件引用格式，手机消息中提供文件预览入口。
- 扩展审批：目录/网络权限可逐项勾选并选择本轮或会话范围。支持常见 MCP 文本、数字、布尔、单选和多选表单，以及 URL 授权。复杂表单和需电脑完成的身份验证保留明确提示。
- 新增可选「后台任务提醒」：通过当前模式/服务下已配对电脑的加密连接，提醒任务完成、出错和待审批，点击回到对应电脑与对话。默认关闭；不会自动批准请求或发送消息。
- 后台连接使用安卓前台服务，不依赖 Google Play；可在设置或常驻通知关闭。电脑需保持运行；安卓厂商的省电、系统网络限制、强行停止 App 等会影响及时性。
- 管理员账号提醒与任务提醒使用独立通知清理；切换自建中继时后台读取该服务自己的凭据，不会转发其他服务 Token。

手机和电脑连接器均需更新至 0.8.0；本版中继 API 不变，无需升级中继。安装包继续保留预设公网配置；公开源码保持脱敏。Windows 11 实机验收仍待完成。详见 [使用手册](USER_GUIDE.md) 和 [验收记录](verification-0.8.0.md)。
