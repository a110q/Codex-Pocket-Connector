# 0.9.17.1 电脑连接器验证记录

日期：2026 年 11 月 19 日。对外版本 0.9.17.1，构建号 51。本次生成 Windows、macOS 和 Android 本地测试包，候选更新清单已签名但未同步到公网或更新服务。问题修复在电脑端，不要求重装手机 App。

## 手机创建的对话接续和管理

- Pocket 状态监控不再订阅自己的会话。任务和审批结束后，即使桌面正在查看，也关闭该对话的独立进程，确认退出后再通知桌面刷新。正在运行或待审批的对话保留原进程。
- 手机归档、恢复和删除通过已有的 Pocket 进程或目录服务执行，不再先恢复对话另抢一个写入锁。归档和删除后检查列表结果；另一个 Codex 客户端确实仍占用时不会强抢，也不会显示操作成功。
- 在隔离目录用实际 Codex App Server 验证：另一个进程在 Pocket 持有时被拒绝，释放后可以按同一个 ID 接续并归档；Pocket 持有时能直接删除，释放后能不经恢复直接归档。归档、删除结果用真实列表回读确认。
- 单元测试覆盖桌面跟随、已知空闲不加载整段历史、保护待审批、未确认退出不能视为已释放、外部占用不重试。官方桌面界面的输入恢复和真机手机端到端流程尚未验收。

## Windows 连接器启动

- 旧弹窗对应 Pocket 后台在返回就绪状态前退出，并不检查 Codex 是否登录。新版先验证 Node 版本与实际可用的 `node:sqlite`，启动失败时按阶段显示诊断编号。连接页面未就绪便出错时退出本地监听，防止错误伪装成超时。
- `%LOCALAPPDATA%\Codex Pocket\startup-diagnostic.txt` 仅记录版本、失败阶段和诊断编号；不含配对信息、原始报错或访问令牌。仍失败时，只需发该文件或弹窗截图。现有本地配置不自动清空。
- `npm test`：230 项通过。Windows EXE 内嵌包和 ZIP 解包校验通过，ZIP 清单内 933 文件通过 SHA-256 校验。Windows 包内 Node 后端在 macOS 隔离状态目录完成启动和关闭检查。macOS `.app` 临时签名校验和原生后台启动检查通过。
- **未通过 Windows 实机验收**：未在截图机器上运行 EXE、PowerShell/WPF、WebView2 或与本机 Codex 配对，旧版退出的具体原因尚未确认。Windows EXE 未做 Authenticode 代码签名；EXE 和 ZIP 的 SHA-256 清单已另行签名。macOS `.app` 未做 Apple 公证。
