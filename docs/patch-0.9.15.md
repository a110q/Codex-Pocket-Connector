# 0.9.15 更新说明

公开版本 0.9.15，构建号 43。

1. 手机对话正文支持 Markdown 图片，按原位置保留图片、文字、列表和表格的顺序。支持普通图片链接、引用式图片、列表和表格内的图片；代码示例中的图片语法不会触发加载。本地图片沿用会话授权及加密文件通道，网络图片使用独立连接，支持缓存、失败重试和点击查看。
2. “交付与修改”默认折叠，只显示标题、数量和展开箭头；点击后显示文件和修改摘要，再次点击收起。会话实时刷新保留用户的展开选择。
3. 修复电脑移除项目后手机继续显示的问题。项目迁移完成后使用当前项目数据判断项目是否存在，避免旧记录恢复已移除的项目；手机前台连接期间约每 5 秒自动同步项目新增、改名及移除。移除项目不删除对话记录。
4. “全部、运行中、待审批”支持左右滑动切换，点击标签也会切换页面；屏幕外的预加载页不暴露重复的可访问性内容。

手机和电脑连接器均需使用本版，才能完整应用项目列表修复。中继协议兼容现有服务，无需更换账号或重新配对。

安装包已生成于 releases 的对应平台目录；本轮未切换线上更新频道。Windows 连接仍待实机验收。
