# 电脑连接器 0.7.5：新建、会话交接与删除同步

手机新建使用已安装 Codex 的 App Server，不再依赖只允许受信任进程调用的 App Tools。独立对话按桌面可识别的日期目录保存，项目内对话保留项目归属；首次提交后通知桌面更新侧栏。手机和桌面操作同一个对话 ID。

手机发起的每条活动对话使用独立后台进程。回复完成后，确认没有运行中的轮次或审批请求，再关闭该进程并等待退出，释放写入锁；其他对话不受影响。仅取消订阅不会释放引擎写入锁，不能解决“已在另一个应用中打开”。电脑接着打开这条对话即可继续，手机再发送时优先跟随已有桌面持有者。运行中保留单个写入者，避免并发破坏历史。

删除先确认后台记录确实移除，再通知桌面清除缓存入口；归档、恢复也发送对应刷新。对已经删除的 ID 再请求删除，会确认两类列表中均不存在并再次清理桌面入口。运行中的任务不能删除；若电脑仍持有会话，需先关闭该对话页面再管理。

明确发生在提交前的错误会返回失败并解除手机待确认状态；可能已经提交的请求继续保留待确认，防止重复创建或重复发送。旧版留下的待确认记录需要核对后手动清除，不会自动重发。

更新：退出旧 Pocket 连接器，打开 0.7.5。安卓继续使用 0.7.2，账号、服务器配置和配对保留。原来已经显示写入锁错误的桌面页面，更新后点击一次「重试」。新建时保持 Codex 桌面打开。

验收：92 项 Node 回归通过。独立应用由 LaunchServices 启动，确认 App Tools 仍被拒绝时，完成真实新建、两轮消息、进程退出后其他客户端恢复同一 ID、再次释放写入锁；没有绕过桌面来源校验。另用验收测试对话完成真实归档、恢复和永久删除，并验证数据库列表和桌面刷新通知。测试记录只保存在项目 `.private`。Windows 仍待 Windows 11 实机验收，构建成功不代表已经连接验收。
