# 0.9.15.1 验证记录

日期：2026-11-02。公开版本 0.9.15.1，构建号 44。

## 根因证据

初次排查时，桌面项目工具返回 14 个可见项目，数据库及官方 project/list 返回 15 个；后者包含桌面可见清单中没有的临时验收项目。projectsMigrated 为 true，但 threadAssignmentsMigrated 为 false，侧边栏的 local-projects 与桌面工具清单一致。上一版的测试只覆盖数据库记录删除及手机收到变更清单，未覆盖这个真实数据源差异。

优先以桌面可见清单决定项目存在性；不可用时，在对话归属迁移尚未完成的情况下使用当前侧边栏状态。清单中已消失的项目不能从 canonical 项目表、旧 ID 映射或 project/list 合并回来。不修改用户的项目数据库，也不删除对话来隐藏问题。

## 验证结果

- Node 全量 207 项通过。补充侧边栏移除后底层仍有记录、旧 ID 映射残留、空清单、桌面连接失败时的后备清单、失败保留缓存所需的错误返回等回归。
- 使用本机真实桌面目录验证：修复后的清单与桌面项目工具逐项一致，已移除的临时验收项目不存在，正常项目和对话保留。
- 通过独立 TLS 中继、真实 CipherChannel 和 companion 的 projects.list 请求，客户端收到与桌面一致的 14 个项目；测试没有接管用户的手机连接，也没有修改真实项目。
- 验证期间电脑新增了 baoleiji_shell 项目，因此后续清单为 15 个。使用新的桌面清单重新核对打包后的 Mac 连接器，主路径及强制 IPC 失败后的后备路径均与当前 15 个项目一致；已移除项目仍不存在。打包验证中桌面工具管道拒绝直接诊断进程，实际验证通过的是侧边栏状态后备路径，不能将其描述为工具管道验证成功。
- 三端按项目约定命令打包成功。Mac codesign 严格校验通过；Windows ZIP 完整性通过，关键模块与源码一致，package.json 数据一致；APK 原有发布签名验签通过，版本 0.9.15.1 / 44。Windows 打包脚本会去除 package.json 末尾换行，故此文件按 JSON 内容比较。
- 本次没有修改 Android 业务源码，沿用 0.9.15 已通过的前台轮询及错误保留缓存行为；未重复运行 Android 模拟器交互测试，未观察用户手机屏幕。
- 已切换本机运行实例到新 Mac 包。状态显示 connected=true、mobileOnline=true、error 为空；电脑身份与配对密钥摘要未变化。原先两个旧实例均已退出，目前只运行新实例。
