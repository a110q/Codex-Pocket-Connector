# 0.9.16.1 更新说明

版本：0.9.16.1，构建号：49。

- 修复新版 Codex 桌面端发送 v13 会话数据后，手机进入会话就提示“电脑接口已变化”、连接器主动断开的兼容问题，同时保留 v11 支持。
- 运行状态监听使用相同的兼容规则，恢复新版桌面的运行状态同步。
- 无关会话、其他来源的未知版本广播不再触发全局断连。正在订阅的会话若使用未支持的版本，仍会明确拒绝，避免把未同步内容当作最新状态。
- Windows 启动时，在加载 WebView2 前，仅解除本应用附带的 WebView2 库的下载阻止标记；失败时给出中文处理提示。
- “打开下载位置”增加 Windows Shell 备用打开方式；更新页显示可选中复制的完整路径。打开失败会保留已验证的安装包，不再提示重新下载。

Android 同步版本为 0.9.16.1 / build 49，手机功能沿用 0.9.16；Windows 11 实机验收仍待完成。发布附件包含三端安装包及 SHA-256 校验清单。
