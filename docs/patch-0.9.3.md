# 0.9.3：重复连接与断线布局修复

三端统一 **0.9.3**，中继无需升级。保留 0.9.2 的操作回执恢复、电脑切换、重命名及重新绑定修复。

## 连接稳定性

同一电脑身份出现两个连接实例时，中继让新的连接接管。此前旧实例把“已被替换”当成普通断网，自动重连并挤掉新实例，导致双方反复重连。

现在手机与电脑连接器收到明确接管通知后停止抢占，显示原因。临时断网、丢失心跳与握手超时仍自动重连。HTTP 401/403、设备撤销及账号授权失效也不再进行无意义的无限重试；恢复授权后可手动连接。

电脑端「连接 Codex」可以重新启用被接管的连接，无需重建电脑身份、清除配对或改动项目。关闭重复实例后再使用此操作。

## 手机聊天布局

- 合并重复的连接和错误提示，详细原因点「详情」查看。
- 待确认操作压缩为一行，点「查看」核对结果；清除记录仍需要二次确认，操作正在提交时不可清除。
- 键盘弹出后保留输入框和发送按钮，断线时可以继续编辑草稿，发送仍受连接与待确认状态限制。
- 离线时不再把旧快照显示为实时“Codex 正在处理”。

这些修复不代表所有网络环境中的掉线都已消除。电脑休眠、网络中断、连接器退出及授权变更仍会影响连接。此轮没有取得用户 Windows 设备的现场日志，不能把所有旧版截图归因于同一个问题。

测试证据与限制见 [验收记录](verification-0.9.3.md)。
