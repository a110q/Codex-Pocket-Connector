# 0.9.9 手机界面

视觉基准为用户提供的 `codex_pocket.html`，项目内留档在 `design/review/0.9.9/reference.html`。该文件只作为设计参考，不将示例模型、命令、电脑、状态或演示脚本当作产品功能。

## 视觉规范

- 背景 `#F8FAFD`、卡片 `#FFFFFF`、次级表面 `#F1F4FA`。
- 主色 `#4355B9`；用户气泡 `#EEF1FF`，描边 `#DCE2FF`，文字 `#1E2547`。
- 薰衣草表面 `#F3F0FF`、描边 `#E4DFFF`；主文字 `#191C24`、次文字 `#525866`、辅助文字 `#7C8496`。
- 顶栏 60 dp，边距 16 dp；卡片圆角 14–16 dp，面板顶部圆角 18 dp；主要操作触控区至少 48 dp。
- 中文使用 Android 系统字体；正文 15.5 sp、行高 25 sp，代码和项目名使用系统等宽字体。深色模式保留相同层级，使用适配后的深色表面与靛蓝色。
- 聊天主入口的返回、更多、附件、发送、终端、配置和文件夹图标直接由参考稿 SVG 转为 Android VectorDrawable。

## 真实功能映射

- 顶部电脑名称打开电脑切换面板，读取已配对电脑并调用现有切换流程；管理入口进入电脑管理页。
- 更多操作打开底部面板，保留项目文件、网页预览、工作空间工具、交付、重命名及刷新。
- 用户消息右对齐，右上角小圆角；电脑回读的消息标注已同步。电脑队列消息继续区分排队、发送、暂停及结果待确认。
- 助手回复改为全宽开放正文；运行中的尾部回复显示流式状态。
- 执行过程采用一行折叠摘要和状态标记，展开后仍为独立懒加载记录。失败摘要独立显示，折叠执行过程也能看见失败，并可打开真实记录详情。
- 审批卡片进入聊天内容流，保留批准本次、拒绝、详情以及服务器实际允许的决策范围。问题回答和扩展权限审批仍走原有真实处理流程。
- 运行配置合并为一行，打开统一面板；可选模型、推理强度来自电脑，权限语义继续使用实际产品的工作区、只读和完全访问。
- 附件面板保留图片、文件选择，并提供电脑文件引用入口。
- 输入框右侧在有草稿/附件时发送；运行中且没有新内容时停止。断线、待确认操作及忙碌限制继续生效。
- 返回最新内容使用浮动按钮，避免额外占用输入区高度。

## 与参考稿样例的区别

参考稿的模型名称、时间、测试命令和网络切换提示属于示例数据。产品展示真实数据，不伪造发送时间、网络恢复结果或成功审批。参考稿的“重试命令”演示没有对应的可安全通用重试接口，产品使用“查看记录”进入完整详情，避免误执行命令。权限标签保留现有真实授权含义。
