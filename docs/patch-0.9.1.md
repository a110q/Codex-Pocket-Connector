# 0.9.1 界面与多电脑提醒修复

手机工具页按小屏重新排版，并根据电脑实际能力展示可用操作。电脑连接器和 APK 配套更新；中继协议保持兼容。

## 手机界面

- 工具目录改为双列卡片，突出当前电脑及连接状态。
- 技能列表支持搜索、筛选与名称展示，简介最多两行。正文和来源位置放入详情，不再让长说明与完整路径占满列表。
- 工具服务使用中文状态；电脑管理、Token 认证或不支持网页认证的服务不显示 OAuth 按钮。
- 普通文件夹、未安装 Git 或项目不是仓库根目录时，显示对应说明并隐藏提交、推送等不可执行操作。兼容旧连接器返回的非仓库错误。
- 受管理的插件不提供卸载与启停；要求官方安装告知或组织策略禁止安装的插件引导到电脑处理。
- 用量入口调整为「会话统计」。保留真实 Token、上下文与可读取的额度；不再展示认证失败的空额度卡片。
- 暂时移除手机「创建 PR」入口。连接器接口保留，待真实授权与完整流程验证后再恢复。
- 定时任务列表收紧留白，最近执行记录默认最多展示三项。

## 多电脑提醒

在设置中开启「后台任务提醒」并允许 Android 通知后：

- 手机停留在电脑 B 时，电脑 A 的审批、完成与失败仍可提醒。
- 同一台电脑的其他对话复用当前连接轮询，不另开争抢连接的手机通道。
- 后台继续监控已配对的局域网电脑，以及当前中继账号有权访问的公网电脑。
- 通知标注电脑与对话；点击切换到对应电脑并打开对话，审批发送到该电脑。
- 同名审批按电脑隔离并去重；切换电脑时保留其他电脑的监控连接。
- 超过 30 个候选对话时分批轮询，保留尚未读取和读取失败的队列。

电脑、Codex 与连接器需要持续运行。公网只使用当前服务账号的授权，不向其他中继发送登录凭据。第三方 Android 后台限制仍可能影响锁屏通知，强行停止 App 后无法继续监控。

原生截图、测试结果和未验证环境见 [验证记录](verification-0.9.1.md)。
