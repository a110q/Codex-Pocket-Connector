# 功能覆盖与剩余边界

0.9.0 已加入对话重命名、项目文件树/搜索/@引用、Git 差异/审查/提交/推送/草稿 PR、技能与插件管理、Pocket 定时任务、额度与 Token 界面和扩展审批。文件上传、多电脑切换和后台提醒已在前版实现。

仍受接口或验证环境限制的范围：Windows 11 实机连接、更多安卓厂商后台限制、不同身份服务的 OAuth 回调、OpenAI 专用身份验证/输入控件、官方原生定时任务互通、完整终端及远程主机目录。独立账号接口未返回额度时不会估算。

本版用法和限制见 [更新说明](patch-0.9.0.md) 与 [使用手册](USER_GUIDE.md)。
