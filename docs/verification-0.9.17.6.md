# Codex Pocket 0.9.17.6：Windows 旧数据目录升级

Windows 旧版可能已把目录访问权限限制到配对用户和系统，但仍保留内置管理员组作为目录所有者。从 0.9.17.3 起，启动检查会拒绝这种布局；0.9.17.4 修正了新建目录时的所有者，没有迁移已存在的目录。

本版只接受保护继承边界、仅允许当前配对账户和系统访问、且当前用户具有可继承完全控制权限的旧目录。不接管旧目录，不改写通过验证的权限，不清空本地状态或配对。其他账户拥有的目录，以及由管理员组拥有但权限不安全的目录，继续拦截，并给出不同的提示。

升级验收需要在 Windows 上用旧配对数据覆盖打开；普通 Windows 账户可直接双击，不需要以管理员身份运行。自动化使用临时测试目录模拟旧权限，不读取真实配对目录。
